## 📚 仓库简介

本仓库用于整理和维护自然资源领域技术标准、规范规程、法律法规、政策文件及相关参考资料。

其中，**技术标准与规范**按照自然资源部2022年5月发布的《自然资源标准体系》组织，并结合实际文件管理需要进行专业细分；**法律法规及政策文件**单独设置 [`法律法规`](./法律法规/) 目录，按业务主题分类管理，避免与技术标准体系混排。

## 🔎 快速查找

- **标准列表**：进入 [`标准目录.md`](./标准目录.md)，按分类折叠/展开浏览，并可直接打开标准文件。
- **法律法规**：进入 [`法律法规目录.md`](./法律法规目录.md)，按业务主题折叠/展开浏览。
- **仓库检索**：使用 GitHub 仓库搜索，可按标准号、文件名或关键词检索。
- 在两个目录页面中均可直接使用浏览器 `Ctrl + F` 快速定位。

## ⚖️ 法律法规分类

法律法规、部门规章、规范性文件、司法解释及相关管理文件统一存放在 [`法律法规`](./法律法规/) 目录，目前按以下主题整理：

`综合法律` · `测绘地理信息` · `国土空间规划` · `土地管理与不动产` · `矿产与生态资源` · `农村集体与农业农村` · `招标投标与政府采购` · `劳动人事与社会保障` · `司法解释` · `财务管理` · `无人机与航空`

## 📝 文件命名

技术标准文件统一采用：

```text
标准号简写 标准名称.pdf
```

例如：

```text
GBT 18314-2024 全球导航卫星系统（GNSS）测量规范.pdf
CHT 1001-2005 测绘技术总结编写规定.pdf
DZT 0484-2024 遥感地质术语.pdf
```

法律法规文件原则上直接使用**正式文件名称**，去除原上传文件名前的流水号、日期后缀、网站来源字样和“文字版”等无关标记。
