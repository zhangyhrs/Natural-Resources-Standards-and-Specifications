## 📚 仓库简介

本仓库用于集中整理自然资源领域的**技术标准、规范规程、法律法规、部门规章、规范性文件、政策文件及相关参考资料**，重点服务于自然资源调查监测、确权登记、国土空间规划、测绘地理信息、土地资源、矿产资源、生态保护修复等业务。

| 资料类型 | 组织方式 | 入口 |
|---|---|---|
| **常用资料** | 高频标准与常用业务资料快速入口 | [常用资料速查](./常用资料速查.md) |
| **技术标准规范** | 自然资源部2022年《自然资源标准体系》 | [标准目录](./标准目录.md) |
| **法律法规** | 法律效力层级 → 业务领域或地区 | [法律法规目录](./法律法规索引.md) |
| **全部资料** | 总索引 + GitHub 搜索 + 自动文件清单 | [总索引](./总索引.md) |

## 🧭 快速查找

- **常用资料**：优先进入 [常用资料速查](./常用资料速查.md)，快速定位高频标准。
- **按标准号**：进入 [标准目录](./标准目录.md)，或搜索 `18314`、`TD/T 1112` 等关键词。
- **按法律法规名称**：进入 [法律法规目录](./法律法规索引.md)，按法律效力层级和业务领域/地区浏览。
- **按关键词**：使用 [仓库检索](https://github.com/zhangyhrs/Natural-Resources-Standards-and-Specifications/search)。
- **新上传资料**：先放入 [待整理](./待整理/)，完成校核后再归入正式目录。

## 🗂️ 组织体系

### 📘 技术标准体系

技术标准统一存放在 [`标准规范`](./标准规范/) 目录，按照自然资源部《自然资源标准体系（2022）》组织：

| 代码 | 子体系 | 代码 | 子体系 |
|---|---|---|---|
| TY1-00 | 基础通用 | DJ2-00 | 自然资源调查监测 |
| GH2-00 | 国土空间规划 | ZC2-00 | 自然资源确权登记与权益 |
| LY2-00 | 自然资源开发利用 | DC2-00 | 用途管制与督察执法 |
| ST2-00 | 国土空间生态保护与修复 | TD2-00 | 土地资源 |
| DZ2-00 | 地质与矿产资源 | HY2-00 | 海洋 |
| XX2-00 | 自然资源信息化 | CH2-00 | 测绘地理信息 |

### ⚖️ 法律法规体系

法律法规统一通过 [`法律法规目录`](./法律法规索引.md) 浏览，采用“**法律效力层级 → 业务领域或地区**”的双重分类：

| 一级分类 | 二级分类方式 |
|---|---|
| 01 宪法 | 综合 |
| 02 法律 | 按业务领域 |
| 03 行政法规 | 按业务领域 |
| 04 部门规章 | 按业务领域 |
| 05 地方性法规 | 按地区 |
| 06 地方政府规章 | 按地区 |
| 07 司法解释 | 按案件或业务领域 |
| 08 规范性文件与政策文件 | 按业务领域 |

每条资料附加 `时间` · `发布机关` · `业务领域/地区` 标签；同一二级分类内按文件名称**汉语拼音 A–Z**排序。

## ⭐ 常用资料速查

针对日常项目使用频率较高的资料，单独建立 [常用资料速查](./常用资料速查.md)，目前包括大地测量与控制、地籍与房产测绘、成果质量检查、技术设计与总结、土地评价与估价、常用术语等主题。该页面只做高频入口，不替代完整标准目录。

## 🔄 自动文件清单

仓库新增 `scripts/build_inventory.py`，用于扫描 `标准规范` 和 `法律法规` 目录，并自动生成：

- `catalog_auto.csv`：适合筛选、统计和二次处理；
- `文件清单_自动生成.md`：适合快速浏览仓库现有文件。

GitHub Actions 会在标准规范、法律法规或生成脚本发生变化时自动更新文件清单。人工维护的 [标准目录](./标准目录.md) 和 [法律法规目录](./法律法规索引.md) 仍作为主要业务索引，不会被自动脚本覆盖。

## 📝 文件命名

技术标准实体文件统一采用：

```text
标准号简写 标准名称.pdf
```

例如：

```text
GBT 18314-2024 全球导航卫星系统（GNSS）测量规范.pdf
CHT 1001-2005 测绘技术总结编写规定.pdf
DZT 0484-2024 遥感地质术语.pdf
```

GitHub 文件名中不使用 `/`；在标准目录和索引中仍按正式标准号显示为 `GB/T`、`CH/T`、`DZ/T` 等。法律法规实体文件原则上直接采用**正式文件名称**。
