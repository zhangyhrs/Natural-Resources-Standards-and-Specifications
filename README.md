## 📚 仓库简介

本仓库用于整理和维护自然资源领域技术标准、规范规程、法律法规、部门规章、政策文件及相关参考资料。

其中，**技术标准规范**按照自然资源部2022年5月发布的《自然资源标准体系》组织；**法律法规**按照法律效力层级组织，并辅以业务领域、时间和发布机关标签进行检索。

## 🔎 快速查找

为减少逐层进入文件夹查找的操作，仓库提供以下方式：

- **标准列表**：进入 [`标准目录.md`](./标准目录.md)，按分类折叠/展开浏览，并可直接点击标准名称打开文件。
- **法律法规索引**：进入 [`法律法规索引.md`](./法律法规索引.md)，按“宪法 → 法律 → 行政法规 → 部门规章 → 地方性法规 → 地方政府规章 → 司法解释 → 规范性文件与政策文件”浏览。
- **拼音排序**：法律法规在同一层级内按文件名称汉语拼音 A–Z 排序，同一首字母下继续按第二个字及完整名称拼音排序。
- **标签检索**：法律法规条目附加 `文件日期`、`发布机关`、`业务领域` 标签，便于快速判断和筛选。
- **仓库检索**：使用 GitHub 仓库搜索，可按标准号、标准名称、法规名称或关键词检索。
- **CSV 索引**：通过 [`catalog.csv`](./catalog.csv) 进行结构化查询、筛选和后续维护。

## ⚖️ 法律法规分类体系

法律法规采用法律效力层级作为一级分类：

1. 宪法
2. 法律
3. 行政法规
4. 部门规章
5. 地方性法规
6. 地方政府规章
7. 司法解释
8. 规范性文件与政策文件

当同一层级文件较多时，再按业务领域细分，如自然资源与土地、测绘地理信息、国土空间规划、矿产资源、林草湿地、农业农村、招标采购、劳动保障等。

## 📝 文件命名

标准 PDF 文件统一采用：

```text
标准号简写 标准名称.pdf
```

例如：

```text
GBT 18314-2024 全球导航卫星系统（GNSS）测量规范.pdf
CHT 1001-2005 测绘技术总结编写规定.pdf
DZT 0484-2024 遥感地质术语.pdf
```

文件名中不使用斜杠；在标准列表、`catalog.csv` 或其他索引中按正式标准号 `GB/T`、`CH/T`、`DZ/T` 等展示。
