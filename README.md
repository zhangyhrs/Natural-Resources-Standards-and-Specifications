## 文件命名

GitHub 文件名不能使用半角 `/`，因此 PDF 文件名中的标准号采用全角斜杠 `／`，例如 `GB／T`、`CH／T`、`DZ／T`；在 `catalog.csv`、README 和其他索引中仍按正式标准号 `GB/T`、`CH/T`、`DZ/T` 记录。
