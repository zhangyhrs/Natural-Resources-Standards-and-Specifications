## 📚 About

This repository maintains technical standards, specifications, regulations, policies and reference documents for the natural resources sector. The repository structure and standard classification follow the <strong>Natural Resources Standards System (2022)</strong> issued by the Ministry of Natural Resources of China.

## 🗂️ Classification

Formal documents are stored under [`标准规范`](./标准规范/) and organized by the corresponding standard-system codes, including TY, DJ, GH, ZC, LY, DC, ST, TD, DZ, HY, XX and CH.

## 🔎 Catalog

The master index is maintained in [`catalog.csv`](./catalog.csv), including standard number, title, category, status, replacement relationship, file path and source information.

## 📥 Incoming Files

Newly uploaded and unclassified documents may first be placed in [`待整理`](./待整理/) and moved to the appropriate formal category after review.

## 📝 File Naming

Use the format <strong>standard number + official title</strong>. Since GitHub file names cannot contain the half-width slash `/`, PDF file names use the full-width slash `／` in standard numbers, for example:

```text
GB／T 18314-2024 全球导航卫星系统（GNSS）测量规范.pdf
CH／T 1001-2005 测绘技术总结编写规定.pdf
DZ／T 0484-2024 遥感地质术语.pdf
```

In `catalog.csv`, README files and other indexes, standard numbers should still use their official forms such as `GB/T`, `CH/T` and `DZ/T`.
