## 📚 仓库简介

本仓库用于整理和维护 **自然资源领域技术标准、规范规程、政策法规及相关参考资料**，便于标准文件的分类存储、快速检索、版本管理和持续更新。

仓库分类结构按照 **自然资源部2022年5月发布的《自然资源标准体系》** 组织。该体系围绕自然资源综合管理、自然资源门类以及自然资源信息化和测绘技术等业务领域建立统一的标准分类框架，本仓库据此设置一级目录，并结合实际收录文件进一步细分专业类别。

## 🗂️ 分类体系

标准文件统一存放在 [`标准规范`](./标准规范/) 目录，一级分类按照《自然资源标准体系》设置：

- `TY1-00 基础通用`
- `DJ2-00 自然资源调查监测`
- `GH2-00 国土空间规划`
- `ZC2-00 自然资源确权登记与权益`
- `LY2-00 自然资源开发利用`
- `DC2-00 用途管制与督察执法`
- `ST2-00 国土空间生态保护与修复`
- `TD2-00 土地资源`
- `DZ2-00 地质与矿产资源`
- `HY2-00 海洋`
- `XX2-00 自然资源信息化`
- `CH2-00 测绘地理信息`

其中，目录代码沿用《自然资源标准体系》的分类代号和层级表达方式。对于测绘地理信息等标准数量较多的类别，在一级体系下继续按照专业内容设置二级、三级目录，便于浏览和管理。

## 🔎 标准目录

仓库总目录统一维护在 [`catalog.csv`](./catalog.csv) 中，记录标准号、标准名称、一级分类、二级分类、标准状态、替代关系、文件路径、来源及备注等信息。

随着标准数量增加，建议优先通过 `catalog.csv` 进行检索，再通过分类目录查看对应 PDF 文件。

## 📥 待整理文件

新上传但尚未完成分类的文件，可统一放入 [`待整理`](./待整理/) 目录。完成标准号、名称和专业类别核对后，再移动至正式分类目录。

## 📝 文件命名

统一采用：

```text
标准号 标准名称.pdf
```

例如：

```text
TDT 1015.2-2024 地籍数据库 第2部分：自然资源.pdf
```

原则上保留正式标准号和正式标准名称，不附加下载网站名称、无关时间戳、重复前缀等内容。

## ✅ 维护规则

- 原则上一份标准对应一个 PDF 文件。
- 标准号和标准名称尽量采用正式发布文本中的写法。
- 分类优先依据《自然资源标准体系》确定，必要时再根据标准具体内容细分专业目录。
- 修订、废止、被替代的标准不直接删除历史记录，在 `catalog.csv` 中保留状态和替代关系。
- 暂时无法准确判断分类的文件先放入 `待整理`，核实后再归档。
- 来源链接优先采用自然资源部、国家标准全文公开系统及相关标准发布机构等权威来源。
