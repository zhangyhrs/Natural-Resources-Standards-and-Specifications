## 📚 仓库定位

本仓库用于集中整理和维护自然资源领域的**技术标准、规范规程、法律法规、部门规章、规范性文件、政策文件及相关参考资料**，重点服务于自然资源调查监测、确权登记、国土空间规划、测绘地理信息、土地资源、矿产资源、生态保护修复等业务场景。

仓库采用“两套体系、统一索引”的组织方式：

| 资料类型 | 组织原则 | 主要入口 |
|---|---|---|
| **技术标准规范** | 按自然资源部2022年《自然资源标准体系》组织 | [标准目录](./标准目录.md) |
| **法律法规** | 按法律效力层级组织，业务领域作为二级分类和标签 | [法律法规索引](./法律法规索引.md) |
| **全部资料** | 统一通过索引、GitHub搜索和CSV辅助检索 | [总索引](./总索引.md) |

## 🧭 快速查找

- **想找某个标准号**：进入 [标准目录](./标准目录.md)，或直接搜索 `18314`、`TD/T 1112` 等关键词。
- **想找某部法律法规**：进入 [法律法规索引](./法律法规索引.md)，按法律层级和拼音浏览。
- **不知道属于哪一类**：进入 [总索引](./总索引.md) 或使用 [仓库检索](https://github.com/zhangyhrs/Natural-Resources-Standards-and-Specifications/search)。
- **新上传资料**：统一先放入 [待整理](./待整理/)；完成校核后再归入正式目录。

## 🗂️ 技术标准体系

技术标准统一存放在 [`标准规范`](./标准规范/) 目录，按照自然资源部2022年《自然资源标准体系》组织：

`TY1-00 基础通用` · `DJ2-00 自然资源调查监测` · `GH2-00 国土空间规划` · `ZC2-00 自然资源确权登记与权益` · `LY2-00 自然资源开发利用` · `DC2-00 用途管制与督察执法` · `ST2-00 国土空间生态保护与修复` · `TD2-00 土地资源` · `DZ2-00 地质与矿产资源` · `HY2-00 海洋` · `XX2-00 自然资源信息化` · `CH2-00 测绘地理信息`

## ⚖️ 法律法规体系

法律法规按照法律效力层级作为一级分类：

**01 宪法 → 02 法律 → 03 行政法规 → 04 部门规章 → 05 地方性法规 → 06 地方政府规章 → 07 司法解释 → 08 规范性文件与政策文件**

当同一层级文件较多时，再按业务领域细分。索引中的条目统一增加：

`时间` · `发布机关` · `业务领域`

同一分类内按**文件名称汉语拼音 A–Z**排序；首字母相同时继续比较第二个字及完整名称拼音。

## 📝 文件命名

技术标准实体文件统一采用：

```text
标准号简写 标准名称.pdf
```

例如：

```text
GBT 18314-2024 全球导航卫星系统（GNSS）测量规范.pdf
CHT 1001-2005 测绘技术总结编写规定.pdf
DZT 0484-2024 遥感地质术语.pdf
```

GitHub 文件名中不使用 `/`；在标准目录和索引中仍按正式标准号显示为 `GB/T`、`CH/T`、`DZ/T` 等。

法律法规实体文件原则上直接采用**正式文件名称**，不保留上传时的流水号、来源网站字样和无意义后缀。
