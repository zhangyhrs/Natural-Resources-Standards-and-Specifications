## File naming

GitHub file names cannot contain the half-width slash `/`, so PDF file names use the full-width slash `／` in standard numbers, e.g. `GB／T`, `CH／T`, `DZ／T`. Catalogs and indexes retain the official forms `GB/T`, `CH/T`, `DZ/T`.
