## 📚 仓库简介

本仓库用于整理和维护 **自然资源领域技术标准、规范规程、政策法规及相关参考资料**，服务自然资源调查监测、地籍调查、不动产与自然资源确权登记、测绘地理信息、遥感、GIS 等业务场景。

仓库目录和标准分类 **按照自然资源部2022年5月发布的《自然资源标准体系》组织**。该体系围绕自然资源管理职责和专业领域设置基础通用、自然资源调查监测、国土空间规划、自然资源确权登记与权益、自然资源开发利用、用途管制与督察执法、国土空间生态保护与修复、土地资源、地质与矿产资源、海洋、自然资源信息化、测绘地理信息等标准子体系。

## 🗂️ 分类体系

正式标准统一存放在 [`标准规范`](./标准规范/) 目录，并按照《自然资源标准体系》对应代号组织：

- `TY1-00 基础通用`
- `DJ2-00 自然资源调查监测`
- `GH2-00 国土空间规划`
- `ZC2-00 自然资源确权登记与权益`
- `LY2-00 自然资源开发利用`
- `DC2-00 用途管制与督察执法`
- `ST2-00 国土空间生态保护与修复`
- `TD2-00 土地资源`
- `DZ2-00 地质与矿产资源`
- `HY2-00 海洋`
- `XX2-00 自然资源信息化`
- `CH2-00 测绘地理信息`

其中，`1`、`2`、`3` 等数字表示标准体系层级；双字母表示标准子体系代号。实际文件管理时，可在上述子体系下继续按专业门类设置二级、三级目录。

## 🔎 标准目录

仓库总目录统一维护在 [`catalog.csv`](./catalog.csv) 中，记录标准号、标准名称、分类、现行状态、发布日期、实施日期、替代关系、文件路径、来源链接及备注等信息。

## 📥 待整理文件

新上传但尚未归类的标准，可先放入 [`待整理`](./待整理/) 目录，核实后再移动到对应的正式分类目录。

## 📝 文件命名

统一采用“**标准号 + 标准名称**”形式。由于 GitHub 文件名不能使用半角 `/`，PDF 文件名中的标准号采用全角斜杠 `／` 表示，例如：

```text
GB／T 18314-2024 全球导航卫星系统（GNSS）测量规范.pdf
CH／T 1001-2005 测绘技术总结编写规定.pdf
DZ／T 0484-2024 遥感地质术语.pdf
```

在 `catalog.csv`、README 和其他索引中，标准号仍按正式写法记录为 `GB/T`、`CH/T`、`DZ/T` 等。

## ✅ 维护规则

- 原则上一份标准对应一个 PDF 文件。
- 标准号、名称尽量保持官方正式写法。
- 修订、废止、被替代的标准不直接删除历史记录，应在 `catalog.csv` 中标记状态和替代关系。
- 暂时无法准确判断分类的文件先放入 `待整理`，核实后再调整。
- 来源链接优先使用政府部门、标准发布机构或其他权威来源。
