## 📚 仓库简介

本仓库用于整理和维护 **自然资源领域技术标准、规范规程、政策法规及相关参考资料**，重点服务自然资源调查监测、地籍调查、不动产与自然资源确权登记、测绘地理信息、遥感、GIS 等业务场景。

分类以《自然资源标准体系（2022）》为主框架，测绘地理信息部分再参考《测绘标准体系》细分，便于将不同来源、不同结构的标准统一纳入管理。

## 🗂️ 分类体系

当前标准统一存放在 [`标准规范`](./标准规范/) 目录，主要按下列体系组织：

- `TY1-00 基础通用`
- `DJ2-00 自然资源调查监测`
- `GH2-00 国土空间规划`
- `ZC2-00 自然资源确权登记与权益`
- `LY2-00 自然资源开发利用`
- `DC2-00 用途管制与督察执法`
- `ST2-00 国土空间生态保护与修复`
- `TD2-00 土地资源`
- `DZ2-00 地质与矿产资源`
- `HY2-00 海洋`
- `XX2-00 自然资源信息化`
- `CH2-00 测绘地理信息`

其中测绘地理信息标准进一步按 **定义与描述、获取与处理、检验与测试、成果与服务、管理** 等类别细分。

## 🔎 标准目录

仓库总目录统一维护在 [`catalog.csv`](./catalog.csv) 中。建议记录标准号、标准名称、分类、现行状态、发布日期、实施日期、替代关系、文件路径、来源链接及备注等信息。

## 📥 待整理文件

新上传但尚未分类的标准，可统一放入 [`待整理`](./待整理/) 目录，整理后再移动到正式分类目录。

## 📝 文件命名

统一采用：

```text
标准号 标准名称.pdf
```

例如：

```text
TDT 1015.2-2024 地籍数据库 第2部分：自然资源.pdf
```

原则上保留正式标准号和正式标准名称，不附加下载网站名称、无关时间戳和重复前缀。

## ✅ 维护规则

- 原则上一份标准对应一个 PDF 文件。
- 标准号、名称尽量保持官方正式写法。
- 修订、废止、被替代的标准不直接删除历史记录，应在 `catalog.csv` 中标记状态和替代关系。
- 暂时无法准确判断分类的文件先放入 `待整理`，核实后再调整。
- 来源链接优先使用政府部门、标准发布机构或其他权威来源。
