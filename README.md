## 📚 仓库简介

本仓库用于集中整理自然资源领域的**技术标准、规范规程、法律法规、部门规章、规范性文件、政策文件及相关参考资料**，重点服务于自然资源调查监测、确权登记、国土空间规划、测绘地理信息、土地资源、矿产资源、生态保护修复等业务。

| 资料类型 | 组织方式 | 入口 |
|---|---|---|
| **技术标准规范** | 自然资源部2022年《自然资源标准体系》 | [标准检索](https://zhangyhrs.github.io/Natural-Resources-Standards-and-Specifications/) / [标准目录](./标准目录.md) |
| **法律法规** | 法律效力层级 → 业务领域或地区 | [法规检索](https://zhangyhrs.github.io/Natural-Resources-Standards-and-Specifications/laws.html) / [法律法规目录](./法律法规索引.md) |
| **常用资料** | 高频标准与常用业务资料快速入口 | [常用资料速查](./常用资料速查.md) |
| **全部资料** | 总索引 + 自动文件清单 | [总索引](./总索引.md) |

## 🧭 快速查找

- **标准检索**：可按标准名称、标准号、标准层级、标准性质、标准体系和专业分类筛选。
- **法律法规检索**：可按法规名称、法律效力层级、业务领域或地区、发布机关筛选。
- **常用资料**：优先进入 [常用资料速查](./常用资料速查.md)，快速定位高频标准。
- **新上传资料**：先放入 [待整理](./待整理/)，完成校核后再归入正式目录。

## 🗂️ 组织体系

### 📘 技术标准体系

技术标准统一存放在 [`标准规范`](./标准规范/) 目录，按照自然资源部《自然资源标准体系（2022）》组织：

| 代码 | 子体系 | 代码 | 子体系 |
|---|---|---|---|
| TY1-00 | 基础通用 | DJ2-00 | 自然资源调查监测 |
| GH2-00 | 国土空间规划 | ZC2-00 | 自然资源确权登记与权益 |
| LY2-00 | 自然资源开发利用 | DC2-00 | 用途管制与督察执法 |
| ST2-00 | 国土空间生态保护与修复 | TD2-00 | 土地资源 |
| DZ2-00 | 地质与矿产资源 | HY2-00 | 海洋 |
| XX2-00 | 自然资源信息化 | CH2-00 | 测绘地理信息 |

### ⚖️ 法律法规体系

法律法规统一通过 [`法律法规目录`](./法律法规索引.md) 浏览，采用“**法律效力层级 → 业务领域或地区**”的双重分类：

| 一级分类 | 二级分类方式 |
|---|---|
| 01 宪法 | 综合 |
| 02 法律 | 按业务领域 |
| 03 行政法规 | 按业务领域 |
| 04 部门规章 | 按业务领域 |
| 05 地方性法规 | 按地区 |
| 06 地方政府规章 | 按地区 |
| 07 司法解释 | 按案件或业务领域 |
| 08 规范性文件与政策文件 | 按业务领域 |

每条资料附加 `时间` · `发布机关` · `业务领域/地区` 标签；同一二级分类内按文件名称**汉语拼音 A–Z**排序。

## ⭐ 常用资料速查

针对日常项目使用频率较高的资料，单独建立 [常用资料速查](./常用资料速查.md)，目前包括大地测量与控制、地籍与房产测绘、成果质量检查、技术设计与总结、土地评价与估价、常用术语等主题。该页面只做高频入口，不替代完整标准目录。

## 🔄 自动索引与检索

仓库通过 `scripts/build_inventory.py` 自动扫描 `标准规范` 和 `法律法规` 资料，并为 GitHub Pages 生成检索数据。标准检索页与法律法规检索页随仓库更新自动重新部署。

人工维护的 [标准目录](./标准目录.md) 和 [法律法规目录](./法律法规索引.md) 仍作为业务分类依据，自动检索页面主要用于快速筛选和定位。

## 🕒 更新记录

仓库的重要结构调整、批量资料更新和索引优化统一记录在 [CHANGELOG.md](./CHANGELOG.md)，方便了解近期新增内容和维护情况。
